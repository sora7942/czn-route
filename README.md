# 카오스 내비

카오스 제로 나이트메어의 카오스 맵 스크린샷을 올리면 칸과 연결선을 자동으로 인식하고, 원하는 칸을 가장 많이 밟는 루트를 계산해 주는 정적 웹 페이지입니다.

https://sora7942.github.io/czn-route/

## 사용법

1. **스샷 올리기** — 맵을 왼쪽에서 오른쪽으로 옮기며 찍되, 인접한 스샷끼리 **2열 이상 겹치게** 합니다. `Ctrl+V` 붙여넣기, 끌어놓기, 파일 선택(여러 장) 모두 됩니다. 순서가 틀리면 썸네일 순서를 바꿉니다.
2. **가중치 정하기** — 칸 종류별 점수를 조절하거나 프리셋을 고릅니다. 음수도 됩니다.
3. **루트 보기** — 점수가 가장 높은 상위 3개 루트가 탭으로 나오고, 다이어그램에 경로가 표시됩니다. 현재 위치(출발 칸)를 지정하면 거기서부터 다시 계산합니다.
4. **틀리게 인식됐다면 수정 모드** — 칸 종류 바꾸기, 칸 추가·삭제, 연결선 추가·삭제를 할 수 있고, 수정하면 루트가 바로 바뀝니다. 되돌리기와 JSON 내보내기가 있습니다. 인식이 애매한 곳은 추측하지 않고 경고로 표시합니다.

스샷은 원본 PNG(캡처 그대로)를 권장합니다. WebP·JPEG처럼 손실 압축된 이미지나 축소한 이미지는 안전 구역/웨이포인트나 흐린 칸을 잘못 읽을 수 있고, 이어붙이기가 실패할 수도 있습니다. 올린 스샷 썸네일 아래에 브라우저가 읽은 이미지 크기가 표시되니, 문제가 생기면 먼저 그 크기를 확인하세요.

## 개인정보

스샷은 **브라우저 밖으로 나가지 않습니다.** 인식과 계산은 전부 내 브라우저(Web Worker) 안에서 처리되고, 서버로 업로드하지 않습니다.

## 로컬 실행

빌드가 없는 바닐라 HTML/CSS/JS(ES modules)입니다.

```
python -m http.server -d docs 8000
```

http://localhost:8000 을 엽니다. `file://`로 직접 열면 module worker가 막혀 동작하지 않습니다.

테스트(Node 18+):

```
npm install
npm test
```

## 구조

- `docs/` — 배포되는 사이트. `docs/core/*`는 DOM에 의존하지 않는 순수 모듈(인식·루트 계산·수정)이고, `docs/app.js`만 DOM을 만집니다.
- `tests/` — Node 내장 테스트와 fixture(스샷 + 정답 JSON)
- `reference/` — 검증용 Python 프로토타입과 게임 내 공식 명칭을 확인한 범례 스샷
- `SPEC.md` — 요구사항, 알고리즘, 단계
